# Ralph loop files

- `SPEC.md` what to build. `CONTRACTS.md` shared interfaces and file ownership. `DECISIONS.md` calls made without asking. `PROGRESS.md` per-round status.
- `tasks/<area>.md` checklists: `- [ ]` open, `- [x]` done, `- [!]` blocked. One item = one Claude session.
- The engine that runs these lives in the RalphLoops repo; this folder is only the loop's inputs and notes.
